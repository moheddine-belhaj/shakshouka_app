# shakshouka_app


## Short description 

ShakshoukAI is an AI-powered app that reads and analyses your documents using n8n workflows and an OpenAI agent. It helps you sort them by category and urgency, search through your documents (pictures, PDFs, text files, and more), and create tasks from timelines, with more features to discover.
This is a [Next.js](https://nextjs.org) project bootstrapped with [v0](https://v0.app).

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) **20 or newer** (LTS recommended). Check with `node -v`.
- [Git](https://git-scm.com/) installed.
- **npm** (comes with Node). Alternatively you can use [yarn](https://yarnpkg.com/) or [pnpm](https://pnpm.io/).

### 1. Clone the repository

Replace the URL with your real remote (HTTPS or SSH):

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```

If you already cloned elsewhere, open a terminal in the project root (the folder that contains `package.json`).

### 2. Install dependencies

From the project root:

```bash
npm install
```

This downloads packages listed in `package.json` into `node_modules/`.

### 3. Run the development server

```bash
npm run dev
```

The app starts with [Next.js](https://nextjs.org/) in development mode (hot reload, detailed errors). By default it listens on **port 3000**.

### 4. Open the app

In your browser go to:

[http://localhost:3000](http://localhost:3000)

If port 3000 is busy, Next.js may pick another port; check the terminal output for the exact URL.
